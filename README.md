# KillerBayer FBO

Статический прототип маркетплейса для Якутии с демо-админ-панелью.

## Запуск локально

```bash
python -m http.server 8000
```

Откройте:
- `http://localhost:8000/` — основной сайт.
- `http://localhost:8000/catalog.html` — каталог.
- `http://localhost:8000/category.html?gender=men&category=shoes` — пример категории.
- `http://localhost:8000/local.html` — локальный закуп.
- `http://localhost:8000/process.html` — процесс закупа.
- `http://localhost:8000/b2b.html` — B2B-зона.
- `http://localhost:8000/admin.html` — админ-панель (сохранение в localStorage).
